# 小学口算闯关

一个给小学生练口算的单页小游戏。三种模式：限时闯关、积分刷题、乘法口诀背诵。题目实时生成，答案和中间步骤都在 81 以内，除法按乘法口诀反着出（商永远不超过 9）。

**零依赖**：整个游戏就是一个 `index.html`，没有 CDN、没有字体、没有图片、没有音频，双击即用。

**在线玩**：<https://wuwuii.github.io/kids-math-quiz/>

## 三种模式

| 模式 | 玩法 |
|---|---|
| 计时模式 | 总时长 2 分钟，每题单独限时（3/5/8/10/12/15/18/20 秒可选，默认 8 秒），比答对题数 |
| 积分模式 | 不限时，一直做，手动结束结算，比得分 |
| 口诀背诵 | 固定 45 句（1×1、1×2…1×9，然后 2×2…2×9，一直到 9×9），全程计时，比总用时 |

## 题型

加减乘除四种可选，也能同时出现加减和乘除（如 `6×3−5`），混合运算按「先乘除后加减」求值并分步显示。

难度分 Lv1~Lv5：一位数 → 几十±一位数 → 两位数 → 三数 → 四数；也可固定某一级。自动挡下每答对 3 题升一级，Lv5 封顶。

## 几个细节

- 答错会显示正确答案和每一步过程，点「下一题」继续；计时模式下答错期间总倒计时暂停
- 答对 720ms 后自动下一题，带撒花和音效
- 口诀背诵模式答错留在原句、清空重输，错满 3 次给出正确答案；计时不停
- 结算页可导出错题 txt（一行一题、Tab 分隔，Excel 直接分列），文件带 BOM，Windows 记事本不乱码
- 最高分 / 最快用时存在浏览器 localStorage
